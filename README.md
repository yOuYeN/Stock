# 看懂金流 × 週末快充｜國際到台股

兩個單元，用白話文看懂台股主流：

- **看懂金流**：每日台股 **成交值 TOP20 × 三大法人（外資/投信）× 美股/日股** 金流觀察。
- **週末快充**：每次挑一個產業，搞懂「為什麼好公司營收能一再創高」——源頭、龍頭、護城河、產業鏈。

開啟首頁 [`index.html`](index.html)（建議用 GitHub Pages：`https://youyen.github.io/Stock/`）。
